# 주석

- ※ 이동률(%) : 인구 백명당 이동자수 = 이동자수/연앙인구*100
- - 전입률은 전입자수, 전출률은 전출자수, 순이동률은 전입자수와 전출자수의
- 차이로 계산
- - 연앙인구 : 1992년까지는 추계인구사용, 1993년부터는 주민등록인구연앙인구 사용
- * 주민등록연앙인구=[연초 주민등록인구+연말 주민등록인구]/2
- * 시도 주민등록인구 자료는 1992년부터 집계되어 시도 이동률은 1993년부터
- 제공가능,시군구 연령별 이동자수 자료는 1995년부터 집계되어 시군구 이동률
- 은 1995년부터 제공가능
- * 연중 행정구역 변경시 주민등록연앙인구는 변경된 행정구역을 기준으로 연초
- 변경전 인구와 연말 변경후 인구의 평균, 이동자는 행정구역 변경전 이동자와 변경후 이
- 동자의 합으로 이동률 계산
- 2010년 7월 1일 창원시, 마산시, 진해시가 통합되어 통합 창원시 신설
